# Security policy

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting for this repository (Security tab → Advisories → Report a vulnerability), when enabled. If private reporting is unavailable, contact the repository maintainers through a private GitHub channel and ask for a secure reporting route.

Please do not disclose exploitable vulnerabilities in public issues, discussions, or pull requests before maintainers have had a reasonable opportunity to investigate and coordinate a fix. Include affected versions, impact, and safe reproduction details; avoid sharing real user data or credentials.

We will acknowledge reports and coordinate any public disclosure after a fix or mitigation is available. No personal contact details are required for reporting.
