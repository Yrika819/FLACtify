# FLACtify v3.0.0 — リリース候補ノート

**状態：BLOCKED / 未リリース**

この文書はリリース候補の確認用です。正式リリース、署名、配布を示すものではありません。

## 主な変更候補

- 再生キュー、スマートプレイリスト、ライブラリのバックアップ・復元を追加。
- Opus音源のタグ編集と、外部LRC読み込みの信頼性を改善。
- ミニプレイヤーを追加し、アートワークに連動した暗色配色を採用。
- SAFフォルダ、検索、ライブラリ走査の改善を含む。

## リリースを保留している問題

プレイ統計をバックアップから復元した後、通常の読み込み処理が復元した値を認識しません。次回の再生・スキップ記録で復元済み統計を上書きする可能性があります。修正と回帰確認が終わるまでv3.0.0はリリースしません。
