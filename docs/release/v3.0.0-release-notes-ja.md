## Phase 10A-R1 修正記録

初回候補レビューで、バックアップ復元後の再生統計形式が通常保存形式と異なり、次回の再生・スキップ記録で値を失う可能性が見つかりました。このP0はDraft PR #37で修正し、v2.5.2保存形式・旧バックアップ形式の互換性、rollback、journal retry、不正・競合データ保全を回帰試験に追加しました。独立レビューでは統計復元に残存P0/P1ブロッカーは見つかっていません。

PR #37は`main`向けDraftのままです。最終HEADのGitHub必須CIとOwner実機再検証、Gate 3 paused-retentionリスクの最終判断、正式統合、production署名および本番更新は完了していません。この文書は正式リリースを示しません。
