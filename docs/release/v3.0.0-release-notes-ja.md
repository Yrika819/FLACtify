## 主な変更

- 再生キュー、スマートプレイリスト、ライブラリのbackup/restoreを追加。
- Opus音源のtag編集、外部LRC読み込みの信頼性を改善。

- SAF folder、検索、ライブラリ走査を改善。
- 再生統計のbackup restoreで内部保存形式と交換形式を分離し、復元後の統計消失リスクを修正。

## 統計復元修正

通常保存形式`pc/sc/lp`とbackup形式`playCount/skipCount/lastPlayed`を個別codecで扱います。既存v2.5.2データと旧backupの両方を読み取り、復元、merge、rollback、journal retryで内部形式を維持します。異常・欠落・競合行は推測で上書きせず保全します。Owner実機で修正を確認し、P0 blockerは解除されました。
