# FLACtify v3.0.0 — 個人利用向け正式安定版

**状態：正式確定（2026-11-28）。配布範囲：Owner個人利用。**

GitHub ReleaseやAPK/AAB一般公開は行っていません。

## 主な変更

- 再生キュー、スマートプレイリスト、ライブラリbackup/restoreを追加。
- Opus音源のtag編集、外部LRC読み込みの信頼性を改善。
- ミニプレイヤーとartwork連動の暗色配色を追加。
- SAF folder、検索、ライブラリ走査を改善。
- 再生統計restoreで内部保存形式とbackup交換形式を分離し、復元後の統計消失リスクを修正。

## 再生統計復元修正

通常保存形式`pc/sc/lp`とbackup形式`playCount/skipCount/lastPlayed`を個別codecで扱います。既存v2.5.2データと旧backupの両方を読み取り、restore、merge、rollback、journal retryで内部形式を維持します。異常・欠落・競合行は推測で上書きしません。Owner実機で修正を確認し、P0 blockerは解除されました。

## 既知の制約

- Gate 3再接続時のpaused-retentionは未解決です。通常再生・background操作や再起動後のPASSは再接続試験PASSを意味しません。
- SharedPreferences instrumentationはコンパイル済みですが、全自動suiteは実行していません。
- M3U相対path UIは制約があります。外部LRCはSAF providerにより対応差があります。
- ReplayGain/EQは独立PoCのままで製品再生機能へ統合されていません。
- Android上のPSS、jank、frame timeは定量測定していません。

## 配布

本版はOwner個人利用向けです。一般公開用のLGPL対応ソース・compliance assets配置gateは完了確認されていないため、一般公開APK/AAB、GitHub Releaseはありません。署名済みAPKはOwner限定Driveにあります。Mac側の実測報告が確認できなかったため、署名済みAPKのSHA-256と証明書fingerprintは本書に記載しません。unsigned APKのhashを署名済みAPKのhashとして扱っていません。
